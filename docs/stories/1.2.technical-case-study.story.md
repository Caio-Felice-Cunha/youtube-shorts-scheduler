## Story

1. The deterministic report remains first and demo mode never imports or calls Playwright/CDP.

3. Demo/live boundaries and terms risk are explicit; snippets come from public code.
4. Item traces are interactive, accessible, and safely rendered.
5. README and standard actions expose demo, engineering case, source, and local run paths.
6. Existing tests plus desktop/mobile, keyboard, no-network, injection, secret, and PII gates pass.
